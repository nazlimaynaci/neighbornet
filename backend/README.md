# Backend

Sorumlu: Ömer Saydamoğlu

Dil/çatı ekipçe kararlaştırılacak: Spring Boot (Java) veya NestJS (TypeScript).

## Görevler

- Docker Compose ile PostgreSQL + PostGIS
- `POST /sync` uç noktası (bkz. `docs/sync-api.md`)
- HLC + alan bazlı birleştirme (bkz. `test-vectors/`)
- Kimlik doğrulama (Firebase telefon doğrulama + JWT), roller
- Push bildirim (Firebase Cloud Messaging), moderasyon, KVKK önlemleri
